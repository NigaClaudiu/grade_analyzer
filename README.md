Grade Analyzer

Description

Grade Analyzer is a beginner-friendly Python project that analyzes a list of student grades and calculates useful statistics.

The program uses loops, conditional statements, lists, and basic Python functions to process grades.

Features

Counts how many students passed and failed.
Calculates the total of all grades.
Calculates the average grade.
Finds the highest and lowest grades.
Displays the index of the highest and lowest grades.
Counts grades equal to or above 90.
Displays the grades equal to or above 90 together with their indexes.
Python Concepts Practiced

Variables and data types
Lists
For loops and range()
If and else statements
Indexing
Accumulators and counters
max() and min()
index()
len()
Basic mathematical operations
f-strings
Example Data

grades = [45, 78, 90, 32, 100, 67, 90, 50]

Example Output

Students passed: 6

Students failed: 2

Total grades: 552

Average grade: 69.0

Highest grade: 100

Highest grade index: 4

More 90: 3

Min grades: 32

Lowest grade index: 3

Purpose

This project was created as part of my journey learning Python. It helped me practice working with lists, loops, conditions, indexes, and basic statistics.
